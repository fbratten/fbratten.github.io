# Harnessing Library

Public route: `/harnessing/`, under Methods & Labs.

The browser page introduces harnesses through 15 supporting methods and controls,
30 workplace situations, two six-moment freight-terminal cases, six five-stage
pipeline views, four first-party field notes and six small interactive labs.
CARD and POINTER have independent entries and responsibilities.

The full method selector uses ordinary document scrolling at desktop and mobile
widths. Search and purpose filters are optional. Selecting a method returns to the reading section on desktop and directly to
the reading card on mobile; keyboard focus follows the selected heading.

The terminal cases and workflow applications are authored scenarios. External
field notes retain their own source attribution. This page publishes explanatory
browser code and fictional examples; private implementation code, operational
data, source registers and internal receipts are excluded. No provider calls,
analytics, credentials or persistent browser storage are included.

The HTML is self-contained except for the site's shared navigation assets.
Edit the page, then run `python scripts/build_navigation.py`. Validate with
`python tests/harnessing_library_contract.py` and the navigation contract.
CI exercises desktop/mobile method access, scenarios, pipeline handoffs, small
labs, keyboard behavior and JavaScript-off reading fallback.

Preservation: `archived/harnessing-publication-20261107/manifest.json` identifies
the original public files. Existing method profiles, labs and open PRs are retained.
