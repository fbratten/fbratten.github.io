## Evidence boundaries

- EBNF-RV is a compact domain grammar and regex-backed parser, not a general EBNF parser implementation.
- `FACT`, `TIMELESS` and other tags are producer-assigned classifications, not independent truth proofs.
- `TIMELESS` is an intended semantic marker; this grammar module does not itself implement decay policy.
- Text formatting omits metadata. Dictionary round trip preserves metadata; text format/parse round trip does not.
- Multi-line parsing silently skips non-matching lines.
- Context-stack formatting creates text only. It does not execute a scenario or establish source authority.
- The Rig Veda name records design inspiration and does not claim philological, religious or scholarly fidelity.
- Source-reported test receipts were not rerun for publication.

## Public safety

The page uses synthetic knowledge units only. It contains no private source text, memory records, scratchpad contents, credentials, local paths, tenant identifiers, operator data or source conversations. All laboratories run in browser memory and perform no repository write, source retrieval, LLM call or SPINE execution.
