IPB

IPB preserves one or more bounded independent first-pass attempts before an emerging method, project or capability definition can shape those attempts, then reconciles the preserved baseline against the later formalized approach.

Candidate v0.1 - emerging

Problem

When a system evaluates an approach using evidence produced only after that approach's vocabulary and expected structure are known, apparent validation can become self-referential.

Core model

original problem
→ preserve independent first pass
→ formalize emerging approach
→ compare against preserved baseline
→ reconcile, do not retrofit

Protections

baseline != truth
baseline != control group by default
independence != correctness
comparison != retroactive rewriting

Use

Useful in agentic method development, prompt-system design, architecture work and evaluation where framing lock-in or contamination could otherwise make later evidence look stronger than it is.

Maturity

The governed source classifies IPB v0.1 as an emerging method candidate. This public profile does not claim formal-control status, automated harness maturity or universal evaluation validity.

Emerging public projection. Preserve independent evidence first; reconcile later without rewriting the baseline.
