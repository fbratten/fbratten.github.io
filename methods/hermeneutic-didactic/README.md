## Core distinction

- SPINE iteratively develops an interpretation through model calls, scratchpad rehydration, accumulated questions and RigVedan knowledge units.
- ChangePlane deterministically rereads an already-recorded run, derives one lesson, emits a derived didactic projection, drafts a memory-admission candidate and binds the protocol records into the run's tamper-evident trace.

The systems are complementary but not interchangeable.
