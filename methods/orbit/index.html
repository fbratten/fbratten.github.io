ORBIT

Orientation-Based Recursive Index Tree

ORBIT specifies typed, provenance-aware orientation nodes that tell a small model, larger agent or human what a body of knowledge covers, what it excludes, how authoritative and current it is, and where attention should route next. The backend node remains complete. Each consumer receives a smaller, target-specific projection bounded by hard token gates.

      08

      Scientific interpretation

      ORBIT's source set supports a detailed mechanism and conformance contract. It does not yet support a claim of independently measured outcome improvement.

      Problem definition

      Consumers with limited attention frequently receive either too much source material or summaries that omit exclusions, authority, drift and routing. This creates both context waste and epistemic ambiguity.

      Mechanism hypothesis

      Typed orientation nodes, explicit exclusions, authority barriers, drift warnings, anchors and target-specific token gates should reduce misrouting, silent source escalation and semantic washout. This is a design hypothesis.

      Operationalization

      The accepted v0.1 contract defines backend fields, three edge planes, projection steps, three token formulas, validation phases, manual conformance and fail-loud negative controls.

      Evaluation routes

      Matched studies could measure time-to-correct-source, wrong-route rate, unsupported citation rate, anchor retention, token use, stale-node misuse, regeneration latency and operator correction effort.

      Explicit non-claims

      • ORBIT is not a runtime, retrieval engine, database, graph engine or RAG product.
      • RAG is one possible consumer and is not the framework's identity.
      • The accepted declarative schema is not an executable validator.
      • Manual Conformance is not automated certification.
      • A successfully compiled projection does not make a derived node source truth.
      • A structurally valid projection may still carry a not_safe consumer disposition.
      • The repository-integrity workflow does not validate ORBIT conformance.
      • The orbit-library consistency script does not certify ORBIT Core conformance.
      • No independent effect study was identified in the inspected source set.
