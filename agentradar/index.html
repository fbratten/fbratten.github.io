AgentRadar

When several AI agents share a task, a lead agent can report progress while one of its subagents waits for approval. AgentRadar brings their reports into one view so you can follow the work across projects, machines and runtimes.

Open the English demo Öppna demon på svenska

Follow a task through the team

Find the lead agent

Group the board by project and search for a task. Switch the grouping to machine or runtime to see where the same agents are working.

Inspect its subagents

On a lead agent’s card, open the subagent list. Compare individual tasks and statuses with the counts on the parent card.

Trace a collaboration

Look for a pair of lead agents in the collaboration panel. Use the recent events list to see what each agent reported and when.

What the recording shows

The browser replays a recorded AgentRadar v0.4 session in a loop. All agents, projects and machines in the demo are fictional. Both languages show the same events. Each status reflects an agent’s own report.
