1. Tune your test policy

Move the sliders to explore a hypothetical team's workload. Judge prices, test speed and other assumptions are editable in code but do not represent any provider's live prices.

Fixed illustrative assumptions: fast judge $0.002/case, deep judge $0.02/case, fast judge 3 seconds per case, 20 parallel slots and 4 seconds deterministic CI overhead. These are not benchmark results. Nightly testing stays full coverage in both strategies.

3. Interpret before deciding

What this model supports

Compare explicit test frequencies, call counts, estimated costs and a simple non-failing commit duration bound as you change the policy.

What this model cannot tell you

Failure-detection rate, judge agreement, actual wall-clock latency, prompt variability and production reliability require real test runs and calibration. More sampled cases do not imply a fixed accuracy percentage.

Suggested practice: keep schema, permission and loop checks deterministic; use sampled model evaluations for frequent feedback; reserve broader, reviewable quality checks for PR and nightly jobs.
